# 抓到澤維爾！ / Catch Xavier!

**[▶️ 立即遊玩 / Play Now](https://althea2025.github.io/catch-xavier/)**

一個擁抱的距離，一場小小的偷襲。✨

## 遊戲簡介

Angela 想偷偷從背後抱住 Xavier。問題是，他的警覺性高得離譜。

在午後的書房裡，觀察他的視線、繞過家具、放輕腳步，再用一點魔法把他的注意力引向別處。最後兩步就在眼前——這次能在他回頭之前抱到他嗎？

這是一款單人 **2D 潛行戀愛小遊戲**，帶著乙女遊戲的浪漫、可愛與一點調皮，適合短時間遊玩，也適合不甘心地再試一次。

## 玩法特色

- **觀察與繞行：** Xavier 會閱讀、走動、停留與回頭；利用家具遮蔽視線，找出接近路線。
- **控制腳步：** 普通移動、躡手躡腳與快跑各有用途；不同地面也會影響腳步聲。
- **魔法干擾：** 讓附近物件發聲，引他前往查看，趁機換位置。反覆製造異常聲響，也會讓他起疑。
- **最後幾步：** 就算在背後，距離太近仍可能被察覺；抓準擁抱提示出現的時機！
- **再試一次：** 多種難度與結果演出，搭配桌面操作、手機／平板觸控，以及保存在本機瀏覽器的進度。

## 操作方式

### 電腦

| 動作 | 操作 |
| --- | --- |
| 移動 | WASD／方向鍵，或點擊地板移動 |
| 躡手躡腳 | C 切換開啟／關閉 |
| 快跑 | 按住 Shift；放開後恢復原本移動模式 |
| 擁抱 | 出現提示時按 E |
| 魔法干擾 | Q，或按畫面上的魔法按鈕 |
| 選擇干擾物件 | 點選物件，或 Tab 輪換附近物件 |
| 暫停／繼續 | Esc，或使用畫面按鈕 |
| 重試 | 結局時按 R，或使用結算畫面的重試按鈕 |
| 聲音 | 使用右上角聲音開關 |

### 手機與平板

按住方向鍵移動；點一下「躡手躡腳」切換模式，按住「快跑」暫時加速，放開後恢復。方向鍵可以和動作按鈕同時操作。

靠近後點「抱住」，使用 HUD 的「魔法干擾」施法。也可以點地板移動、點物件選擇干擾目標；暫停與聲音開關位於畫面上方。

## 難度

| 難度 | 適合的體驗 |
| --- | --- |
| RELAXED | 輕鬆觀察、熟悉操作，適合第一次遊玩。 |
| CANON | 推薦的標準體驗，感受最後幾步的心跳。 |
| COMMANDER | Xavier 更敏銳、更難預測，適合熟悉玩法後挑戰。 |

另有隱藏挑戰難度等待發現。

## 結果與演出

- **PERFECT：** 成功從背後抱到他！
- **SO CLOSE：** 就差一點，卻在最後幾步被發現。
- **CAUGHT：** 還沒靠近，就被他看穿了小計畫。

## 遊玩平台

直接在電腦、手機或平板瀏覽器開啟上方連結即可遊玩，不需要下載遊戲、安裝 Node 或其他執行環境。

開啟右上角聲音開關即可聆聽音樂與音效；若裝置沒有聲音，也請檢查系統音量與靜音設定。進度保存在目前瀏覽器，清除網站資料可能會重設進度。

## 使用技術

HTML、CSS、JavaScript、Canvas 2D 與 Web Audio；透過 GitHub Pages 提供靜態網站，使用 localStorage 儲存本機進度。
